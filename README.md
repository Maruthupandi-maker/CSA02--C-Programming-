# CSA02--C-Programming-

This repository contains C programming exercises and practice scripts for the **CSA02** course. It covers fundamental concepts including control structures (if-else, switch), operators (arithmetic, bitwise, relational), and basic algorithms.

## 📂 Programs Included

| Category | Programs |
|----------|----------|
| **Basic I/O & Math** | Addition, Multiplication, Perimeter, Area of Circle/Triangle, Quotient & Remainder |
| **Number Logic** | Odd/Even, Positive/Negative, Divisible by 3 or 5, Single Digit Check, Between 1-100 |
| **Comparisons** | Largest of Two/Three Numbers, Check Smaller Number, Voting Eligibility |
| **Control Structures** | Nested If, Switch Case, Ternary Operator, Grade Calculation |
| **Conversions** | Celsius ↔ Fahrenheit, Int ↔ Hex/Octal/Decimal, ASCII Value |
| **Advanced Concepts** | Bitwise Operators (AND, OR, XOR, Shift), Swapping without Temporary Variable, Post/Pre Increment |
